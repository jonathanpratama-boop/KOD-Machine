## Scope and evidence level

This map inventories **every Python module under `idx-signals/idxsig/`, `kod-machine/kod/` and `tools/` present in the pinned baseline tree**. Each available file was read and parsed for its module purpose, exports and dependencies. The inventory is mechanical breadth coverage, **not a claim that every line received a semantic/security audit**. Deep review covered the collection/timing/control interfaces, immutable evidence boundaries, runtime integration and the studies listed in `PATCHES_RESEARCH.md`. Research results were read as reported evidence; no market-outcome rerun occurred.

Functional ownership below means the subsystem responsible for the contract. Individual maintainers are not assigned by existing source metadata and remain **UNASSIGNED**. This pass does not invent other agents' ownership or change their branches.

## Disagreements and compatibility boundaries

- **Time units:** Binance REST defaults to milliseconds; historical spot ZIP data changes to microseconds in 2025. Do not reinterpret every Binance input as the same unit. Existing daily date keys stay date keys; new event timestamps are UTC-aware.
- **Availability versus label time:** a research next-day-open label is not proof the forecast existed at that open. Preserve labels and add executable references after actual publication.
- **Assessment projection:** candidate overlays select the declared analytical `as_of` cutoff. Actual assessment recording time remains `recorded_at`; an assessment displayed against an older market cutoff does not establish that it existed then. Original assessments and detector records remain retained separately.
- **Cost units:** `profiles.py` uses decimal fractions and tiered price assumptions; Hermes studies use 0.3% per side; the owner's eToro estimate is about1% per side plus spread. Existing studies keep their assumptions. New profiles require named version, provenance and currency; actual account/product fee verification is still required.
- **Markets and mandates:** the BTC/ETH trend paper account is separate from 1–5-session selective repricing, and neither establishes real holdings. Tokenized equity pairs in the current USDT universe are not silently removed from frozen experiments.
- **Identity:** instrument rename, module alias and experiment identity are different concepts. Historical experiment IDs and original byte paths stay canonical; a convenience alias cannot alter an RFC3161 payload.
- **Evidence:** the default branch lacks much of the later Claude/Hermes research. `BRANCH_GAPS.md` lists exact blob differences. No branch merge is part of this pass.
- **Coverage:** all rows received, complete intended membership and whole-market coverage are different claims. Failed requests/no-triggers/expired candidates remain in attempt denominators.
- **Research permission:** the November3 close rule is unresolved while INFO_MAGNET remains not run; later timing instrumentation does not reopen historical early-entry studies.
