Primary thesis, unproven: a dated, binding change in token-holder economics or market access can create a slower repricing opportunity or warning than price-spike/listing-chase signals. A public, well-anticipated change may already be fully priced. The burden is on the test to show useful remaining effects after the information is actionable.

## Three distinct questions

### H1: Cash reaching the token
Hypothesis: a NEW, verified change redirecting external protocol revenue into token-holder distributions or executed token repurchases can increase the token's economic claim or reduce market supply. Project usage and fee growth alone are not enough. A treasury buyback is not automatically a burn or a legal dividend right.

Prediction to lock in a later outcome protocol: affected tokens outperform a fixed market benchmark over five elapsed days after an operationally feasible entry following the verified new information. Positive gross returns without owner-friction headroom do not establish opportunity. Actual first public proposal, approval, implementation and first cash movement must be separate fields; this study may not use implementation as if the plan had never been announced.

Run today: public-source feasibility and independent rights/lifecycle classification. Need exact official proposal, before/after policy, beneficiary, funding source, amounts, implementation transaction/time, supply implications and mapped token contract. Announcement/vote alone stays WATCH. No price effects computed until a sufficient outcome-blind register exists. Current docs/examples were consulted before this charter; this is disclosed hypothesis generation, not pre-registered discovery.

### H2: New dilution or holder-value leakage
Hypothesis: a NEW binding increase in transferable token supply, diversion of holder revenue or treasury sale can reduce value per existing token or create incremental selling pressure. A token mint, vesting release, emissions allocation and actual sale are different events. Predictable scheduled unlocks are not automatically surprises; productive spending may offset dilution.

Prediction to lock in a later outcome protocol: the affected token underperforms a fixed benchmark over five elapsed days following a verified adverse change. This is a warning/research-priority hypothesis, not a short position or an automatic exclusion rule. To count, retain prior schedule/policy and quantitative incremental change; exclude harmless relabellings, internal transfers and cases with unknown beneficiary/token identity.

Run today: source feasibility, classification and false-positive review alongside H1 using the same source pull. Exact supply contracts, vested/transferable amounts and effective timestamps are required. Equity issuance studies do not validate the crypto hypothesis. No token price outcome run until data and rules are adequate.

### H3: Exchange removal warning — first bounded historical test
Hypothesis: an official decision removing an asset from ALL spot trading on Binance predicts negative 24-hour performance relative to BTC/ETH after a one-hour processing delay. Losing one trading pair is not losing the asset's market. A futures-only delisting, collateral haircut or leverage-tier change is a different event and is not pooled into this pilot.

This lane was already owner-approved as part of the exchange-rule register on 1 November. Its detailed protocol is frozen separately in EXCHANGE-DELIST-PROTOCOL.md and published before announcement text/prices. The present task authorizes this bounded batch; no existing research branch or frozen study is changed.

Run today: retrieve the official catalog, validate every primary event and a fixed rejected sample, freeze the source-bound register, then run the fixed historical price test only if the source and sample gates pass. An insufficient or inaccessible sample is a result about feasibility, not a scientific failure/pass of the price hypothesis.

## Efficiency and quality contract

- Reuse current public-data adapters, raw price archives and independent reviewers. Share acquisition between H1/H2, not performance tallies. No parameter grids or winner picking.
- Write exact information/time/identity rules before outcomes. Record all inspected ideas, negatives, retrieval failures and exclusions. Source access is not source completeness.
- Keep historical, current-bootstrap and genuinely prospective observations separate. No backdated forecasts, reconstructed live fills or claims of an untouched holdout on already used years.
- Three hypothesis slots are fixed. Any eventual simultaneous inferential claims use multiplicity correction (alpha 0.05/3), temporal validation, fixed costs and adequate event/cluster counts. More rows from one announcement or token are not independent repetitions. Exact H1/H2 entry/exit/control/cost/sample protocols remain unapproved for computation until source feasibility, so neither is described as a launched return test.
- Historical screening can reject an idea quickly. A positive historical screen earns only a prospective paper test; elapsed future time cannot be replaced by more CPU or repeated scans.
- Keep cash and no qualifying candidate as valid results. No leveraged/short exposure, orders, broker credentials or account allocation in this batch.
- Each lane ends this finite pass with a visible state: SOURCE_READY, NEEDS_EVENT_VERIFICATION, SOURCE_BLOCKED, INSUFFICIENT_EVIDENCE, HISTORICAL_FAIL or HISTORICAL_SCREEN_PASS. Do not leave hidden jobs or claim a continuous scanner was deployed.

## What good results mean
The immediate deliverable is a small, reviewable decision: which information can be measured correctly, which claim survives its locked test, and which specific missing evidence prevents a conclusion. A failed test is useful if it closes an idea; extra code or a plausible story is not a result.

No numeric probability or price target is invented at this stage. H1/H2 directional statements are falsifiable research hypotheses, not calibrated forecasts for UNI, AAVE, SUSHI or any named holding. A case forecast requires current information, a complete economic bridge, alternatives, a dated horizon, invalidation and retained source evidence.
